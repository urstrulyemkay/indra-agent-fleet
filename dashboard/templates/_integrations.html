How this works

The fleet stays operational even when integrations are missing. Every integration is checked at runtime — if required env vars are unset, the dependent agent falls back gracefully (Langfuse → code prompts, Playwright → markdown-only carousels, IG API → paste-mode, etc.). Add an integration's env vars to .env and restart the dashboard to wire it up.
